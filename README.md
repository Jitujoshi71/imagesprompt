# ImagesPrompt — 100 free AI photo prompts

A free, copy-paste library of AI photo prompts for portraits, weddings,
festivals, products and more. These prompts come from
**[ImagesPrompt](https://imagesprompt.in)** — the full library there has
1,162 prompts across 15+ categories, each with an example image, plus a free
prompt builder.

## What's in this repo

| File | What it is |
|---|---|
| `prompts.json` | All 100 prompts as structured data (`title`, `slug`, `category`, `tool`, `prompt`) |
| `PROMPTS.md` | The same 100 prompts as a readable list, grouped by category |

## How to use

1. Pick a prompt from [`PROMPTS.md`](PROMPTS.md) (or `prompts.json` if you are building something with the data).
2. Copy the prompt text.
3. Paste it into your AI photo app — these prompts are written for Gemini image editing: upload your reference photo(s), paste the prompt, and generate.

No writing from scratch, no sign-up, no cost.
